# 本轮执行验收

这是待执行模板，不是已通过的报告。复制到作者包 qa/validation.md，填作者、版本、日期和证据。

| 项目 | 初始状态 | 实际证据 |
| --- | --- | --- |
| 语料覆盖 | NOT_RUN | 范围、源记录数、去重数、有效数、分页结束状态、缺失 |
| 完整阅读 | NOT_RUN | READ_COMPLETE 数、raw 路径、来源映射、截断记录 |
| 量化可靠 | NOT_RUN | 文本来源、分母、计算方法、抽查结果 |
| 规律证据 | NOT_RUN | 核心规则支持 ID、独立样本数、类型 |
| 条件与反例 | NOT_RUN | 反例范围、条件修正、未找到项 |
| 风格与传播分离 | NOT_RUN | 可比组、指标、采集时间、缺失与替代解释 |
| 用户写作指南 | NOT_RUN | 原句来源、选题建议标识、结构与失效条件 |
| 生成力 | NOT_RUN | 留出样本 ID、不同类型试稿、模板趋同与失败项 |
| 事实与声音 | NOT_RUN | 试稿事实来源、经历冒用、全文语气检查 |
| 改写交接 | NOT_RUN | 入口→索引→完整样本的实际读取结果及版本 |

状态只能填 NOT_RUN / PASS / FAIL / BLOCKED / NOT_APPLICABLE；不适用需说明原因且不计为通过。
“设计要求了”不能填 PASS。不能用虚构样本、假计数和假试稿补齐验收。
未执行、失败或受阻时交付草稿并说明限制；仅修改工具只能报告结构校验，不能宣称已经完成某作者蒸馏。
