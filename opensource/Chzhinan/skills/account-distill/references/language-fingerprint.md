# Language Fingerprint · 语言指纹量化

所有可量化结论尽量给出数字，不写模糊形容词。

## 字数与时长

统计：均值、中位数、P25、P75、最短、最长；按内容类型分别统计。

有视频时长时计算：`字符数 / 视频分钟`。

## 句长

至少分桶：

- <10字
- 10–20字
- 21–40字
- >40字

记录均值、中位数、标准差或波动程度。

## 段落

统计：

- 平均 / 中位段落字数
- 一句一段比例
- 2–3句段落比例
- 长段比例
- 段落数量
- 换段触发器

## 标点指纹

每1000字统计：

`， 。 ？ ！ ： ； —— …… “ ” （ ）`

不要只统计次数，还要解释功能：

- 问号用于推进还是情绪？
- 冒号用于解释还是列举？
- 逗号是否形成连续口播？
- 感叹号是否极少或集中在特定内容？

## 词汇与句式

统计：

- 高频词 / 高频短语
- 句首词
- 句尾词
- 转折词
- 强调词
- 否定词
- 疑问词
- 命令词
- 条件词

行业高频词必须剔除后再判断作者指纹。

## 语气 Tone Profile

至少分析：

- 确定程度：强断言 vs 保留判断
- 对观众姿态：老师 / 同行 / 教练 / 研究者 / 朋友 / 老板
- 强度：克制 / 强势 / 吐槽 / 讽刺 / 自嘲 / 兴奋 / 冷静
- 第二人称密度
- 命令语气密度
- 情绪轨迹：稳定 / 上升 / 下降 / 波动

最终输出应是“量化 + 具体例证 + 适用条件”，而不是“口语化、自然、有感染力”。

## 来源与测量限制（v2）
先标注作者稿/人工转写/自动转写及编辑处理。自动标点和换段不作为作者习惯证据。没有原始音视频时不推断真实停顿与语调，字数/视频分钟仅为文本时长比。统计给分母与缺失，按内容类型分组；问句与反问、词频与语义需区分。
