# 传播表现与机制假说

分别回答：作者常用什么（文本复现）、哪些样本表现更好（可比指标）、什么机制可能促成表现（待验证解释）。三者不互相替代。

记录平台、发布时间、指标采集时间、播放/曝光（如有）、赞藏评转分别的数值、账号规模（如有）、内容类型、主题、篇幅、借势对象、投流情况（仅已知时）。缺失记未知，不能推定没有投流。

同作者、同平台、相近主题/类型和时间窗口中比较表现较高与普通/较低样本。说明窗口、分组依据、每组样本数；不按偏好挑案例。同系列单独标记，不作为独立重复验证。不匹配则放弃对照或降级结论。

没有播放量时只能称绝对互动数，不能称互动率、留存或转化。不同发布日期累计数不直接排名；不私设赞藏评转权重生成爆款分。

每个候选机制记录：文本动作与原文位置、预期作用、支持与反例 ID、可比指标、缺失条件、替代解释（热点/知名度/分发/画面/投流）、迁移与失效条件。
结论分“文本观察”“样本内相关”“待验证机制假说”。只有爆款、没有对照时明确选择偏差；未测留存不能说已证实提高留存。相关性不能证明因果。

借势分析说明：借谁/什么事件的注意力、连接受众什么真实问题、移除热点后是否成立。新选题给母问题、新切口、所需事实、受众并标为建议；不制造未经核实的热点事实。
