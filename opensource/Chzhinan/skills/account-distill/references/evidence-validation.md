# Evidence Validation · 规律验证

## 1. 状态

- OBSERVATION：单篇发现
- PATTERN：跨样本重复
- AUTHOR RULE：通过三重验证的稳定规则

## 2. 证据等级

- VERBATIM：原文直接证据
- OBSERVED：客观统计 / 可观察事实
- INFERRED：跨样本推断

## 3. 三重验证

### 复现
至少多个独立样本支持，最好跨不同主题或内容类型。

### 生成力
能否指导一个作者未写过的新题？如果只能解释旧文，不能算核心 DNA。

### 区分度
是不是作者特色，而不是所有好内容都适用的通用原则？

## 4. 重述测试

把原文措辞彻底换掉，规则仍成立 → 机制。

换掉措辞后规则消失 → 可能只是语言表面特征。

## 5. 反例

每条核心规则主动找反例。

如果存在反例：

- 判断是否为内容类型差异
- 判断是否为时间变化
- 判断是否为条件变化
- 必要时把全局规则改成条件化规则

## 6. 置信度

HIGH：多内容类型稳定复现 + 有生成力 + 高区分度。

MEDIUM：多样本出现，但受内容类型 / 时间 / 场景限制。

LOW：少量样本、单一系列、推断较强。

只有 HIGH 默认进入最终作者 SKILL.md 核心。

## v2 判断边界
作者习惯置信度与传播证据强度分开。HIGH 只表示样本支持的条件化倾向，不是所有新题的强制规则。未观察到不能认定永不使用；当前事实、任务与同类型完整原文优先。N 必须附有效样本总数及系列独立性说明。传播归因另遵循 performance-analysis.md。
