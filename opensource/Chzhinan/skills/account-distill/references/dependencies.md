# Dependencies · 依赖与复用建议

- 深度阅读 / long-form reading

参考思想：

- 深度阅读：保证原文完整读取，不以摘要代替。
- PBE：Observation → Pattern → Principle/Rule；保留证据、N、置信度、重述测试。
- Persona / immortal：证据分级、冲突保留、Negative DNA、持续纠正。
- Writing style：量化句长、段落、标点、语气、代词、修辞，而不是只做主观形容。
- Skill-from-memory：最终把研究结果组装成精简 SKILL.md + references / research / qa。
