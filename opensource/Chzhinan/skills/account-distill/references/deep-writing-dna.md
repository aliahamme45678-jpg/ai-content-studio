# Deep Writing DNA · 深层写作决策

## 1. 问题定义

重点找：作者如何把“大问题”压缩成一个具体矛盾、失败结果、可诊断状态或资源约束。

## 2. 开头与 Hook

分别分析：第一句话、第二句话、前三句话。

可能承担：抓注意力、建立问题、扩大矛盾、身份筛选、信息缺口、承诺结果、建立可信度。

## 3. 常用对比 Contrast DNA

记录：对比对象、出现位置、承担功能、适用内容类型。

例如：新手 vs 老手、错误 vs 正确、数量 vs 质量、过去 vs 当前、人工 vs 自动化。

不能只写“喜欢对比”。

## 4. 常用规则 Decision Rule Library

重点抽取：

- 如果 X → 就 Y
- 先 X → 再 Y
- 只有 X → 才 Y
- 不要 X → 先 Y
- 达到 X → 再放大
- 超过 X → 停止 / 淘汰

每条记录：规则、支持样本、反例、适用场景、是否属于临时平台参数。

## 5. Logic Grammar

保存真实推理顺序，例如：

现象 → 推翻原归因 → 新归因 → 判断标准 → 方法 → 再观察。

## 6. Content Archetypes

从真实样本中归纳，不提前固定。可能包括：全链路地图型、故障诊断型、认知纠偏型、现实主义方案型、反向路径型、案例型、教程型等。

## 7. Progression Grammar

研究文章为什么能继续往下走：下一层问题、补条件、出现障碍、阶段切换、结果反馈、重新归因、反例。

## 8. Transition Trigger

分析“为什么转场”，而不是只统计“然后 / 接下来”。

## 9. Evidence DNA

建立 `观点类型 → 常用证据类型` 映射：数据、案例、后台路径、平台机制、操作演示、用户场景、逻辑推导、类比、第三方事实。

## 10. Action DNA

用 L1–L5 表示动作颗粒度：

- L1 原则级
- L2 方法级
- L3 步骤级
- L4 界面级
- L5 参数 / 阈值级

## 11. Ending DNA

分类：结论回扣、重新定义、行动建议、判断标准、下一阶段、开放问题、下一期、自然结束、产品承接。

## 12. Business DNA

分析产品/工具在哪出现、承担什么功能、删掉产品后内容是否仍成立。避免把硬广误当作者写作 DNA。
