# 面向写作的输出

## 给用户的 writing-guide.md

开头交代作者、有效样本量、资料范围与限制。展示最值得借鉴且有证据的写法，不强凑数量。

每种写法用简明卡呈现：
- 别人写什么：真实标题、主题、受众。
- 别人怎么写：前三句或关键承接短引文、来源 ID、完整原文位置。
- 全文结构：各段承担什么作用，保留真实顺序。
- 为什么可能有效：具体内容动作、预期作用；另列表现证据和未知项。
- 我可以写什么：同母问题的新切口、适配受众、所需事实，明确标为建议。
- 怎么借鉴：结构简写、可替换变量和必须满足的证据条件。
- 什么时候不用：主题、语气、受众、事实、篇幅不匹配时的失效条件。
- 反例：真实来源；没找到就注明未找到。

结构公式只是该写法的简写，不是默认模板。不能只写“情绪共鸣+认知重构”而不给原文与动作说明。

## 给 Agent 的作者包

按 data-and-handoff.md 输出作者入口、作者模型、类型框架、样本索引和 raw 完整原文。数字和逐篇研究放 research，详细语言参考仅在有用途时拆分，不强制固定报告数量。

作者 SKILL.md 写明版本、语料范围、验证状态、当前类型路由、完整样本读取方式、规则适用条件与反例。要求比较原稿与候选；事实、用户当前要求、全文一致性优先。禁止冒用作者经历，不将未观察到的写法视为永久禁令。

## 用户汇报
中文简述读了多少/缺多少、可借鉴写法与短例句、指南和作者 Skill 路径、实际检验项目和未验证项。
