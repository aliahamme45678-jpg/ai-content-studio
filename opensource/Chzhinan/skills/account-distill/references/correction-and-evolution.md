# Correction & Evolution · 纠正与进化

当用户说“这不像他 / 他不会这么说 / 这个开头像错了”时：

1. 定位具体句子或结构。
2. 分类：语气 / 结构 / 开头 / 推进 / 标点 / 字数 / 对比 / 规则 / 论证 / 商业植入 / 其他。
3. 回读相关真实样本。
4. 判断：现有 DNA 错误、适用范围过大、还是生成阶段误用。
5. 写入 correction history。
6. 必要时降低 / 提高某条规则置信度。
7. 更新 references 与作者 SKILL.md。
8. 增加版本号并写更新说明。

更新已有作者 Skill 时不要无脑覆盖。先比较新旧 corpus：新增样本、新内容类型、旧规则反例、作者阶段变化。
