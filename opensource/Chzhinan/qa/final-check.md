# Final Check

输出前逐项检查。

## A. 输入与事实

- [ ] 当前主题没有被改丢
- [ ] 核心观点仍然成立
- [ ] 用户事实没有被篡改
- [ ] 原作者经历没有移植成用户经历
- [ ] 没有编造客户、收入、数据、认证、结果
- [ ] 未核实断言保留了必要限定

## B. 改写强度

- [ ] LIGHT / MEDIUM / REBUILD 选择合理
- [ ] 没有为了“改写”而无意义改动
- [ ] 也没有因为“保留”而放过明显结构问题

## C. 素材库

- [ ] 实际完成检索或明确说明不可用
- [ ] 先用选题与借势库确认母问题，而不是只按标题关键词匹配
- [ ] 从爆款文案拆解库精读了 3–5 篇最相关完整原文
- [ ] 改写组件选择数量为 0–2 个，且每个组件都对应原稿的明确缺口
- [ ] 关键候选读取了完整原文
- [ ] 没有只看 AI 标签就声称完成核验
- [ ] 高频模式没有被当成强制公式
- [ ] 没有把多篇样本的最强局部拼成声音不一致的稿子

## D. 作者模式

- [ ] 已加载 `writing-{author}`
- [ ] 若 `writing-{author}` 不存在，已明确使用临时作者校准卡且没有声称生成了作者 Skill
- [ ] 已判断当前内容类型
- [ ] 如果 Writing DNA 可用，已经读取核心分层产物
- [ ] 已读取 3–5 篇最相关完整原文
- [ ] 结构、逻辑、推进、语气与样本相符
- [ ] Negative DNA 没有被违反

## E. Writing DNA

- [ ] 字数区间没有明显失真
- [ ] 句长分布没有明显失真
- [ ] 段落节奏没有明显失真
- [ ] 标点习惯没有被通用规则抹平
- [ ] 结构模板匹配当前体裁
- [ ] 认知框架没有覆盖当前事实

## F. 成稿

- [ ] 开头提出的问题 / 承诺有兑现
- [ ] 中段持续推进
- [ ] 每一段都有新信息或新功能
- [ ] 论证足够支撑强判断
- [ ] 没有机械三点式
- [ ] 没有无依据的反常识
- [ ] 结尾符合当前目标

## G. 去 AI 味

- [ ] 实际执行了 lieflat-less-ai-tone
- [ ] 没有改变事实
- [ ] 没有改变限定词
- [ ] 没有破坏作者稳定 DNA

## H. Author Authenticity Audit

- [ ] 问题定义像
- [ ] 判断方式像
- [ ] 推进像
- [ ] 对比方式像
- [ ] 语言节奏像
- [ ] 不像作者的通用爆款套路已清理

## I. 输出

- [ ] 推荐标题与正文一致
- [ ] 两个备选标题不是同义改写
- [ ] 话题与正文相关
- [ ] 素材依据只列实际使用内容
- [ ] 素材依据优先列 Breakdown ID / source_record_id 与实际借用机制
- [ ] 用户说“只要文案”时没有多余说明
