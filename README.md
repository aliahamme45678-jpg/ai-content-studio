# AI Content Studio

本机私有内容工作台，围绕采集素材、阅读情报、写文案三项工作。Studio 是统一入口；AIHOT 提供情报，抖音流水线提供素材，Hermes 作为写作引擎。原始要求保存在 [PRD](docs/PRD-v1.1.md) 和 [三仓整合方案](docs/integration-plan.md)。

## 使用

运行 `powershell -ExecutionPolicy Bypass -File .\start-local.ps1`，打开 <http://127.0.0.1:4310>。启动本地服务本身不会提交模型请求。`-WithWorker` 另外启动 AIHOT 采集与分析 Worker；不加此参数时不会启动 Worker。

- **采集素材**：视频素材 → 采集任务 → 视频链接或博主主页 → 设置筛选和字段 → 采集 → 按需补转写/评论 → 预检 → 确认入库。视频链接每任务最多 500 条。可导出 Markdown、JSON、飞书用 CSV。未知播放量不会换算成点赞数；设置播放阈值时，未知记录会被排除并单独计数。
- **阅读情报**：找情报 → 直接写文案，或先衍生选题，也可收藏后研究。选题建议基于该条材料，不再为所有新闻返回同一组 Agent 话题。当前角度建议是有来源的编辑框架，不宣称是模型原创观点或已核实的新事实。
- **写文案**：输入选题或粘贴原稿 → 选择写作模板和知识库 → 生成 → 检查 → 修改/定稿 → 复制。来源、所选知识片段、模板快照和稿件版本保存在同一任务中。写作主界面保留生成、检查、保存和复制；详细设置、历史版本及局部修改折叠显示。

“我的素材”支持多份素材共同创作，也可将选中资料保存为命名知识库。知识库分为事实、案例、方法、规则；外部案例不能当作本人经历。选择“自选资料”后只检索明确选择的库/文档；全部不选表示本次不使用知识库。Word/Excel 在本机解析，先预览正文再确认入库。

## 检查与反馈

检查方式在写作设置中选择：本地快检不调用模型；模型诊断读取所选 dbskill 文档，再通过当前模型返回原句、问题及修改建议。后者属于 **Skill 文档辅助诊断**，不等于执行了原 Skill 的全部工具分支，也不代表完成外部事实核验或保证过审。dbskill 为 CC BY-NC 4.0，商业使用须另行核对许可。

替换建议只修改对应原句，其他文字保留；修改后须重新检查。硬性阻断项不能通过忽略或直接修改任务状态绕过。定稿后可登记发布链接和效果；确认的写作经验可存入方法库。不会自动将模型推测升级为个人规则。

## 本机配置

- Studio：4310；AIHOT Web/API：3000/3001；Hermes：8787；PostgreSQL：5432。
- `start-local.ps1` 复用本机已有模型配置启动 Hermes 原生桥接，使用 Studio 提供的模板和知识范围，不读取另一套默认素材来替代它们。桥接由 `app/src/run-hermes.mjs` 生成运行入口，不修改上游 `server.js`。
- ASR Key 和可选评论登录态路径在“连接和设置 → 采集与语音转写配置”中填写。没有 ASR Key 时仍可采集作品数据和导入已有转写。补跑 ASR 时需要确认服务费用。
- 飞书 P0 使用导出/导入与 CSV 文件交接；自动 API 同步和写回保持关闭。X 自动发布不属于 P0。
- 默认启用全站密码入口，未登录不能访问页面和 API；可通过 `STUDIO_PASSWORD` 更换密码，兼容 `STUDIO_TOKEN`。HTTPS 部署设置 `STUDIO_SECURE_COOKIE=true`，详见 [访问密码说明](docs/PASSWORD-ACCESS.md)。默认只监听本机回环地址。数据在 `app/data/`，凭证、登录态、运行时和日志不纳入 Git。
- 结果未知的模型/ASR 请求不会自动重发；核对服务账单后可在任务记录中明确允许重试。

JSON 文件存储适合当前单人本机使用，不用于多用户部署。当前仍是关键词/中文片段检索，不是向量检索。

## 起号分析与采集操作

左侧“起号分析”可直接输入博主主页。全历史模式不套用爆款门槛，分页加载可见作品并保存原始响应；只有收到平台列表末页才标记采集完整。异常分析使用账号点赞中位数、四分位差和前序作品对照，支持按日期筛选、六类作品切换、逐条 AI 证据、账号打法总结与 Markdown 报告。每条分析保存来源、方法版本、模型请求和运行进度；结果未知时不会自动重发。

采集页现在按“采集 → 转写 → 保存/导出 → 写作与 dont 检查”操作。任务卡直接提供转写、Markdown、飞书同步和写作按钮；刷新不清空新建表单。写作台明确区分模板生成、本地规则快检、dontbesilent 方法文档辅助模型检查。

飞书同步通过本机已有 lark-cli 用户身份连接指定内容表；核对字段后保存目标，不保存分享密码。发送前预览新增、已有与缺少正文数量，以来源链接去重；不覆盖已有分析字段，写入回执不明确时停止重试。真实连接配置保存在本机数据目录。Markdown 导出下载文件，与飞书直接同步分开。

已连接飞书时，可在起号分析点击“复用飞书已有正文”，按作者和作品 ID 匹配，只补缺失正文；冲突来源不自动覆盖。也可逐条校对并保留上一版。分析支持完成当前请求后停止、相同输入断点续跑，改正文后旧分类失效。关键跃升展示前 7 天与起始 7 天对照，避免把单条爆款误判为账号常态抬升。

起号图表使用本次采集时的累计互动，不能还原历史每日流量。AI 会给推广/投流倾向及依据；热点原因仍取决于已有材料。语音正文缺失时只分析标题与互动线索。全量语音转写需要配置 ASR 并确认费用。

首页现在直接打开文案工作台：原稿或选题在左侧，生成结果在中间，模板与知识库在右侧；同页检查、逐处修改与定稿。情报和素材入口携带来源进入这一页面。局部重构与历史版本放在结果区的展开项中。

## 2026-10-29 操作恢复与状态

单视频任务可点击“查看作品并选用”，阅读已有正文或粘贴自己的转写，点击“保存正文并带去写作”。保存保留历史版本，不依赖 ASR Key。博主任务保留账号分析入口，混合视频链接不会被当作同一账号计算基线。

模型分析失败不会锁住手动校对或飞书正文补全；运行中的资料处理仍禁止并发覆盖。失败记录可以在网页查看，凭证会隐藏。允许重试与实际重新提交分开，程序不自动重复计费请求。

设置页区分本机配置与最近一次模型调用状态。抖音登录状态可选择本机 storageState JSON 导入，或填写文件路径；保存前验证格式、抖音 Cookie 与过期情况。文件有效不代表平台必然接受登录。未提供“网页登录并自动导出登录状态”的能力。

账号分析改为每批 5 条，提示词只携带分析所需数据；续跑跳过已完成作品。本次没有重新提交真实模型或 ASR 请求，不能据此声称先前 502 已恢复。

写作蒸馏的逐篇精读、证据核对、完整产物导出及部署依赖见 [文字蒸馏说明](docs/WRITING-DNA-PRECISION.md)。
