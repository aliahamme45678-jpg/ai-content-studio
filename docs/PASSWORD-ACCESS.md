# SPX 访问密码

默认启用全站密码保护。首次访问先进入 `/login`，正确登录后才能访问页面、静态资源及业务 API。默认密码使用带盐 scrypt 校验值保存，前端不包含密码。会话有效期 8 小时，退出或服务重启后失效。连续 6 次错误登录会暂停尝试 1 分钟。

部署时可以设置 `STUDIO_PASSWORD` 更换访问密码；未设置时使用本次指定的默认密码。兼容已有 `STUDIO_TOKEN`（优先级低于 `STUDIO_PASSWORD`）。不要在前端、URL 或 Git 中存放明文密码。

通过 HTTPS 反向代理部署时，设置 `STUDIO_SECURE_COOKIE=true`，让会话 Cookie 仅经 HTTPS 发送。Node 服务监听回环地址，由代理转发；不直接暴露内部 AIHOT、Hermes 或数据库端口。本保护覆盖 SPX Node 服务，不代替这些服务各自的访问控制。

这是共享密码入口，两人共享同一工作台数据。页面右上角账号入口支持退出登录。
