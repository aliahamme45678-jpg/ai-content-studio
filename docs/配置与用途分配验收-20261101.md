# 配置与用途分配验收 2026-11-01

配置页分为模型 API、用途分配、飞书、采集与转写、情报来源、高级。模型配置支持新增/编辑，留空保留原 Key，保存时勾选用途；用途分配独立保存。

现有环境模型迁移为现有 API，密钥只存忽略的 app/data/model-profiles.json，API 响应不回显。五项用途已通过页面保存到现有 API，重启后仍保留；后续可分别选择其他配置。用途：writing/intelligence/audit/analysis/distill。写作识别/生成、审核及修改、起号分析、素材提炼均读取对应模型；不再用切换全局模型代替用途分配。

找情报的数据采集仍通过 AIHOT；新增来源卡的 AI 整理会使用 intelligence 模型，带真实来源内容、未知回执拦截和结果缓存，不声称联网检索。

飞书Tab使用已有CLI用户授权，支持目标链接/表ID验证保存与打开飞书。未新增飞书App Secret输入，也未更换现有登录授权。本轮没有调用真实付费模型、没有写入飞书。
