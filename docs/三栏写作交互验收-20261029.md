# 三栏写作交互

根据用户明确的三栏分工调整：左栏为原稿、模板、灵魂风格、黄金三秒、文案类型、知识库和写作引擎；中栏只负责当前文案与修改稿输出；右栏负责检查方法、审核意见及勾选认同后的改写。

旧稿存在时左侧原稿折叠，风格设置直接显示。初始生成和改写按钮固定在左侧滚动区域顶部。右侧意见支持逐条勾选认同，点击“按意见改写”后，AI 修改稿出现在中间；可切换修改前/修改稿对照，采用前不会写入正式正文。点击右侧“采用并复审”后，保存新版本并复审，新正文仍在中间，旧版本保留。

中间的复制操作复制当前显示的文案；预览候选时不显示普通保存按钮，避免跳过采用流程。候选编辑不会被误判为正式正文变化，也不会在采用前通过保存操作写回原稿。检查时中间正文持续可见。左侧设置或正文改变后，右侧明确要求重新检查。

65 项回归通过。使用隔离模拟模型通过浏览器验证：右侧检查 -> 勾选意见 -> 按意见改写 -> 中栏显示修改稿 -> 采用并复审 -> 中栏正式正文更新、可保存定稿。DOM 位置核验确认风格属于左栏、意见属于右栏、候选属于中栏；采用前原正文保留。桌面和 390×844 窄屏检查，窄屏无横向溢出。

本轮没有额外调用真实收费模型。真实稿件的现有审核记录和正文保留；若稿件设置变化，需重新检查后再使用意见改写。
