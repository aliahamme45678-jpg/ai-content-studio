## 发现并修复的问题

| 触发情境 | 原问题 | 修复后 |
| --- | --- | --- |
| 未保存就刷新 | 当前原稿、正文和配置丢失 | 本标签页保留草稿并显示未保存提示 |
| 采用审核修改或恢复历史后刷新 | 旧浏览器草稿可能盖住后台新版 | 优先显示后台版本，冲突草稿独立保留、可手动恢复 |
| 修改中点击新建内容 | 跳过普通导航的保存保护 | 先保存当前稿，失败则留在原稿 |
| 使用绑定资料的模板新建稿件 | 模板继承被存成手动知识覆盖 | 模板知识范围和用户自选范围分开处理 |
| 明确选择空知识范围或更换模板 | 模板自动带入的旧案例仍进入提示词 | 自动案例按当前模板及显式范围过滤，直接选用的原始素材保留 |
| 蒸馏模板另存新版本 | 丢失蒸馏来源和返回流程元数据 | 保留蒸馏关联、灵魂、资料范围和来源返回关系 |
| 改选题、原稿、修改要求或知识范围 | 无问题的旧审核可能再次用于定稿 | 审核指纹覆盖这些配置，必须复查 |
| 选择模型检查但调用本地快检 | 可能借本地报告绕过模型检查 | 定稿验证实际审核引擎 |
| 采用局部修改 | 待重新验证时定稿按钮仍可点 | 前端禁用，后端继续校验；旧报告明确标为上一版 |
| 恢复历史版本 | 历史审核仍显示可定稿 | 使原建议失效并明确要求重新检查 |
| Hermes 写作配置保存、重新打开 | 引擎选择没有持久保存 | 保存并恢复所选写作引擎 |
| 重复导入同一作品只更新互动数 | 被当成重复而不更新数据 | 合并已知互动数据，保留已有正文、标题和已知播放量 |
| 本地检查一个已取消任务 | 检查会重新改变任务状态 | 返回任务已取消，避免隐式恢复 |
| 切换带中文旧方法名的模板 | 方法勾选被清空 | 统一中文别名和正式方法 ID |
| 采集已取得正文 | 仍引导必须先核对入库 | 直接引导看作品、选一篇写作 |
| 飞书同步已写入一条 | 任务卡显示完成 0 | 采用飞书确认的 recordIds 计数，计划写入数不冒充成功数；ASR 新转写与复用分别显示 |
